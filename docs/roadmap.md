# Roadmap de Desarrollo

## Fase 0. Fundación

- Crear repositorio base.
- Scaffolding de backend con Spring Boot.
- Definir arquitectura y estándares iniciales.
- Preparar Docker local para PostgreSQL.

## Fase 1. Identidad y estructura organizacional

- Usuarios
- Roles
- Equipos
- Sponsor / sponsor tree
- Perfil básico

Entregables:

- Modelo de datos inicial
- Migraciones productivas
- Login y refresh token
- Permisos por rol

## Fase 2. CRM comercial

- Prospectos
- Historial de actividad
- Seguimientos
- Archivos y notas
- Filtros, búsqueda y ranking

## Fase 3. Reuniones y productividad

- Meetings
- Participantes
- Resumen por IA
- Tareas y tablero Kanban
- Recordatorios

## Fase 4. Activos y necesidades

- Registro de activos
- Objetivos financieros
- Necesidades del equipo
- Matching de ayuda entre miembros

## Fase 5. Contenido y calendario

- Biblioteca multimedia
- Calendario unificado
- Eventos, cumpleaños y presentaciones

## Fase 6. Comunicación interna

- Mensajería privada
- Grupos
- Adjuntos
- Notificaciones

## Fase 7. Inteligencia y analítica

- Dashboard ejecutivo
- KPIs de conversión y actividad
- Asistente IA contextual
- Recomendaciones automáticas

## Dependencia actual del entorno

Para crear y validar el frontend localmente todavía falta instalar:

- Node.js
- npm

Mientras tanto, el backend y la documentación pueden avanzar sin bloqueo.
